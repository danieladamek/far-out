# FAR Out

A public guide to doing business with the federal government, for any small business: the routes in (SBIR/STTR, Other Transactions, set-asides and vehicles, primes and partnering), the gates on each, the government's side of the table, and an opportunity search built from public feeds.

Status: pre-build. The content pack is being written; this repo currently holds only the source-feed probe (`.github/workflows/probe-sources.yml`), which checks which public opportunity feeds a GitHub Actions runner can reach and how big they are.

Not legal or compliance advice. Every record links to its governing text. No affiliation with any firm or agency.
